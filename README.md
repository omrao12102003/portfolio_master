# Portfolio AI Platform

A quantitative investment research and portfolio management platform combining classical portfolio theory, risk analytics, historical backtesting, reinforcement learning and AI-assisted financial research.

## Project Status

Stage 1 — Architecture and Development Environment

The current stage establishes the software foundation. Quantitative market-data processing, portfolio optimization, backtesting, reinforcement learning and RAG functionality will be implemented in later stages.

## Core Principles

- Financial correctness
- Reproducibility
- Explainability
- Testability
- Realistic assumptions
- Clear separation between quantitative calculations, machine learning, retrieval and LLM-generated explanations

Backtested results represent historical simulations and do not guarantee future performance.
